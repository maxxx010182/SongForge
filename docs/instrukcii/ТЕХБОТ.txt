Техбот — сообщения о сбоях только вам
======================================

Это не бот входа. Бот @SozdaiPesnuLogin_bot не трогать.
Токен в чат с ассистентом не присылать. Только в файл на сервере.

Бот пишет вам в Telegram в трёх случаях:
  1) человеку не собрался текст песни
  2) музыка не запустилась
  3) песня висит дольше 10 минут
Когда снова заработало — одно короткое сообщение.
Одна и та же поломка не повторяется чаще раза в 3 часа.
На ваши сообщения бот не отвечает.


ШАГ 1. Создать бота
-------------------

1) В Telegram откройте @BotFather
2) Команда: /newbot
3) Имя: СоздайПесню Тех
4) Адрес: свой, латиницей, на конце bot.
   Например SozdaiPesnuTech_bot
   Если адрес занят, BotFather попросит другой.
5) BotFather пришлёт токен. Он остаётся у вас.
6) Ещё две команды в BotFather, выбрать этого нового бота:
   /setjoingroups  → Disable
   Так бот нельзя добавить в чужую группу.
7) Домен ему не задавать. /setdomain — это для бота входа, не для этого.


ШАГ 2. Токен на сервер
----------------------

ssh root@195.19.20.245

nano ~/SongForge/.env

В конец файла одна строка, вместо PASTE вставьте токен из BotFather:

TELEGRAM_ALERT_BOT_TOKEN=PASTE

Сохранить: Ctrl+O, Enter, Ctrl+X.


ШАГ 3. Написать боту
--------------------

Откройте нового бота в Telegram и нажмите Start.
Пока он молчит. Это нормально.


ШАГ 4. Команды
--------------

Дальше строки из COMMANDS.txt, блок 26, по одной.
Скрипт должен напечатать:
  CHAT ваше имя
  TEST sent
  DONE
В Telegram придёт «Техбот на связи».
Если CHAT показывает не вас, нажмите Start ещё раз и повторите строку скрипта.

Потом пришлите ассистенту строку health и слова CHAT / TEST sent / DONE.
Токен не присылать.
