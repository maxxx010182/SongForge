Тексты через Kie.ai (все текстовые задачи)
==========================================
Файл: docs/instrukcii/LLM-KIE-PROSTO.txt
Простыми словами. Код: v2.11.33+


═══════════════════════════════════════
ЗАЧЕМ
═══════════════════════════════════════

• Тексты песен, названия, стиль, помощник — через Kie (не Yandex).
• Музыка Suno — как раньше (sunoapi.org / ApiPass), отдельно.
• Один ключ Kie, две модели: PRO (тексты) и LITE (бот).


═══════════════════════════════════════
ЧТО ПОСТАВИТЬ В .env НА СЕРВЕРЕ
═══════════════════════════════════════

LLM_PROVIDER=kie
KIE_API_KEY=ваш_ключ_с_kie.ai
# KIE_BASE=https://api.kie.ai

# Тексты песен (сильнее). 2.5-pro с 29.09 молчит.
LLM_MODEL_PRO=gemini-3.1-pro

# Запас и короткие задачи. 2.5-flash и gemini-3-flash: «канал не поддерживается».
LLM_MODEL_LITE=gemini-3-pro

Потом:
  pm2 restart songforge --update-env


═══════════════════════════════════════
ГДЕ ВЗЯТЬ КЛЮЧ
═══════════════════════════════════════

1) https://kie.ai/api-key — создать ключ
2) Пополнить: https://kie.ai/billing
3) Ключ вставить ТОЛЬКО в .env на сервере (не в чат, не в GitHub)


═══════════════════════════════════════
БАЛАНС В АДМИНКЕ
═══════════════════════════════════════

Откройте https://sozdaipesnu.ru/admin
Блок «Балансы провайдеров»:
  • Kie кредиты — остаток на Kie (тексты)
  • SunoAPI кредиты — остаток sunoapi.org (музыка), если ключ задан
  • Кнопка «Обновить» — перезапросить сейчас

API (для проверки):
  GET /api/admin/provider-balances
  (нужна сессия админа)


═══════════════════════════════════════
ДРУГИЕ МОДЕЛИ (ОПЦИОНАЛЬНО)
═══════════════════════════════════════

Можно сменить slug в .env (path на Kie):
  gemini-3.1-pro
  gemini-3-pro
  gemini-2.5-pro и gemini-2.5-flash с 29.09 не отвечают
  gemini-3-flash — «канал не поддерживается»

Запасные ключи (пусто = выключено, Kie работает как раньше):
  GEMINI_API_KEY — прямой Gemini, другая дверь того же класса
  GEMINI_MODELS=gemini-3.1-pro-preview
  Flash в этот список не ставить: для стихов нужна сильная модель.
  XAI_API_KEY
  XAI_MODELS=grok-4.7,grok-4.6
  CLOUDFLARE_API_TOKEN
  CLOUDFLARE_ACCOUNT_ID
  CLOUDFLARE_MODELS=@cf/meta/llama-3.3-70b-instruct-fp8-fast
  KIE_CLAUDE_MODELS=
  KIE_MODELS=gemini-3-pro,gemini-3.1-pro,gpt-5-2
  ADMIN_MAX_USER_ID — ваш id в MAX, одно сообщение при сбое текста
  TELEGRAM_ALERT_BOT_TOKEN — отдельный техбот, не бот входа
  TELEGRAM_ALERT_CHAT_ID — записывает скрипт привязки, руками не считать

Песню пишет Gemini 3 Pro. Если пришла ошибка — Gemini 3.1 Pro.
Если снова ошибка — GPT 5.2. Сонет не вызываем: на каждую песню он дорогой.
Прямой Gemini с этого сервера не вызывается.
После правки .env: pm2 restart songforge --update-env
