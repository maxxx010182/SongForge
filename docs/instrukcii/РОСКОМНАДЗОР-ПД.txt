Категории данных (галочки)
  Обычно для нас:
  • фамилия, имя, отчество — только если человек сам написал
    (ник / VK). Отчество чаще нет — не ставьте «обязательно ФИО»,
    если не собираете паспорт
  • адрес электронной почты
  • номер телефона (чек / если просили)
  • данные учётки мессенджеров (id, имя)
  • сведения, собираемые метриками — пока нет
  • иные: IP, cookie, история треков, ник, аватар
  Специальные (здоровье, биометрия, судимость) — НЕТ.
  Биометрию (голос как «биометрия») не отмечайте: вы делаете песню,
  не идентифицируете человека по голосу для пропуска.

Действия с данными
  Сбор, запись, хранение, использование, удаление, передача
  (платёжному агенту / по закону). Распространение — только если
  человек сам опубликовал трек на МузПлощадке.

Кому передаём (обработчики, не «продажа»)
  • платёжный сервис GetPlatinum — чек и оплата
  • хостинг/почта REG.RU — письма с кодом входа
  • MAX (бот) — если человек сам пишет боту
  Карты: не передаём, их берёт касса.
  Яндекс.Метрику сюда — только после включения счётчика.

Трансграничная передача (за границу РФ)
  Форма спросит прямо. Не врать.
  Сейчас по факту сервиса:
  • сервер и касса — РФ
  • вход через Telegram — данные у Telegram (не РФ)
  • генерация музыки/текста идёт на API подрядчиков;
    в заказ может попасть имя из идеи песни
  Если не уверены, как именно отметить — один вопрос бухгалтеру
  или в форму РКН «есть трансграничная / Telegram + подрядчики
  генерации, цель — вход и создание трека». Прятать Telegram
  при живом входе через него нельзя.

Меры защиты (ст. 19 152-ФЗ, коротко, как в Политике)
  • HTTPS/TLS
  • доступ к базе только у оператора (ИП)
  • пароли/секреты не в открытом виде, ключи API на сервере
  • разграничение: админка не с главной, только свой email
  • резервное копирование базы (когда cron подтвердите — ок)
  Средства шифрования ФСБ (СКЗИ) — если не покупали Континент/КриптоПро
  для сайта, пишите «не используются» / «штатный TLS». Не выдумывать
  лицензии, которых нет.

Шифровальные средства
  Обычно «не используются» (браузерный HTTPS — не ваш СКЗИ-комплекс).
