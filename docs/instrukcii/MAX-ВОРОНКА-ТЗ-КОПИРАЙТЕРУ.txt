0. ПРОМПТ — ВСТАВЬТЕ ЭТО КОПИРАЙТЕРУ ЦЕЛИКОМ
--------------------------------------------
Ты — старший маркетолог-копирайтер воронок в мессенджерах (MAX / VK / Telegram).
Специализация: прогрев, геймификация без очков, квиз, который сам себя
затягивает, и оффер без цены в лоб.

Задача: спроектировать многоветочный пошаговый сценарий чат-бота MAX
для сервиса «СоздайСвоюПесню» (sozdaipesnu.ru).

Бот — не визитка студии и не анкета. Это живой продажник в чате.
Две работы сразу:
  1) подогреть человека, чтобы он сам захотел открыть студию и услышать песню;
  2) вопросами собрать живой бриф, из которого ИИ-продюсер на сайте соберёт
     сильный промпт. Первая бесплатная проба должна звучать «про них»,
     чтобы захотелось забрать полную версию.

Ниже — продукт, ограничения, провал текущего сценария, что сдать.
Пиши по-русски, живым разговорным языком. Без канцелярита, без «нейросеть
воплотит», без «набросаем», без визитки «мы студия ИИ».
Не продавай цену и пакеты нот в чате.
Не делай магазин с каталогом и корзиной — товара на полке нет.

Сдай:
  A) карту веток (дерево), не одну линейку на всех;
  B) все тексты сообщений бота + подписи кнопок + что делать, если человек
     пишет своими словами;
  C) короткую реакцию бота после каждого ответа (зеркало, не «принято»);
  D) что именно уходит в поле «идея» на сайте после финала
     (структурированный бриф 4–8 строк, не два слова);
  E) тексты дожима, если затих (2 часа / сутки / 4 дня) — разные поводы,
     не «ну как».

Ограничения платформы — в разделе 5. Их нельзя нарушать.

2. ЗАЧЕМ БОТ (метрика успеха)
-----------------------------
Не «поболтать». Не собрать базу для рассылки.

Успех одного захода:
  человек прошёл диалог → открыл студию по кнопке (уже вошёл) →
  в поле идеи лежит живой бриф → нажал «создать» →
  послушал превью и захотел забрать.

Провал (это мы сейчас имеем):
  сухо, как анкета; непонятные вопросы; ветка «себе» ведёт на день рождения;
  человек закрывает чат.

Первая песня покупается, когда в тексте узнают конкретного человека
или конкретную сцену. Значит вопросы бота обязаны вытащить:
  кому (и как называть — мама / половинка / друг);
  зачем сейчас (дата / просто так / не выговаривается);
  одну живую деталь (фраза, привычка, сцена) — это золото для текста;
  как звучит (тепло / драйв / нежно…);
  кто поёт (женский / мужской / дуэт / на твоё усмотрение).

Без живой детали продюсер пишет открытку. С деталью — вещь, которую
ставят в машину.


3. КАК УСТРОЕНО СЕЙЧАС (чтобы не повторять)
-------------------------------------------
Первый экран: картинка-обложка (жест, не логотип) + текст:

  «Есть вещи, которые вслух не выходят. Их можно спеть.
   Соберём новую. Первая проба бесплатно — два варианта, минут пять.
   Стоп — напишите «стоп».»

Владелец на живом тесте:
  — «вещи, которые вслух не выходят» звучит странно, неживой язык;
    ближе по смыслу «то, что вслух не произносят», но нужна ваша формулировка;
  — «Соберём новую… два варианта, минут пять» — сухо;
  — строку про «стоп» на первом экране НЕ НУЖНО. Это априори во всех ботах.
    Нам невыгодно подсказывать остановиться. (Юридическое — см. п. 5:
    соглашение/политика мелко можно, «стоп» не рекламировать.)

Дальше кнопки: Маме / Папе / Ей / Ему / Другу / Себе.
Владелец: сухо и узко. Ближе по духу:
  Моей маме / Моему папе / Моей половинке / Моему дружбану /
  Моей подругане / Конкретно никому / Добавить своё.
Это ориентир тона, не догма. Можно сильнее.

Дальше одна линейка для всех: день рождения / годовщина / просто так /
скоро праздник / хочу сказать и не могу вслух.

Владелец выбрал «себе» — и получил день рождения и годовщину.
Логика хромает: себе обычно не заказывают песню «на др».
Вкладка «себе» как равная «маме» — мимо. Лучше «просто так» /
«другая причина», а не «себе» как персона.

Дальше при «себе»:
  «Для себя — что сейчас внутри? Можно одной сценой.»
  Новая глава / Злость / Кайф / Ностальгия /
  Просто хочу свою песню / Пока без этого.

Владелец: ничего не понятно, отталкивает, не подогревает.

Дальше звук: Тепло и близко / Нежно / Драйв / С улыбкой / Как гимн.
Потом голос: Женский / Мужской / Решите сами.
Голос нужен. Добавить дуэт.
Вместо «решите сами» живее: «мне всё равно, на твоё усмотрение».

Итог владельца: пока сыро. Нужна многоструктурная воронка
с развилками и сюжетами, не один универсальный квиз.


4. ЧТО ДОЛЖНА ДЕЛАТЬ ВОРОНКА
----------------------------
Прогрев. Человек отвечает — и ему становится любопытно, как это прозвучит.
Не квиз ради квиза. Каждый шаг — вклад в «мою песню».

Геймификация без баллов и уровней. Зеркало («держу: маме, свет на кухне»),
«ещё один штрих», в конце не «открыть студию», а «услышать первый вариант».

Ветки, не одна линейка. Минимум разные сюжеты:
  подарок близкому (мама / папа / половинка / друг / подруга / своё имя);
  просто так / без адресата / «никому конкретно» — другая логика вопросов,
  не день рождения;
  «не выговаривается» — отдельный тон, не праздник.
  Своими словами на каждом шаге: «бабушке», «сыну», «8 марта», сцена.

После финала — зеркало собранного черновика своими словами + кнопка
на студию. Человек уже вошёл, идея в поле.

Дожим, если затих после ссылки: 2 ч / сутки / 4 дня. Разный повод.
Не «вы ещё думаете?». Потом молчим. «Стоп» в коде работает, в текстах
первого экрана не светим.


5. ЖЁСТКИЕ РАМКИ (не ломать)
----------------------------
Платформа: MAX, обычный чат-бот. Не мини-приложение, не видео, не магазин.

Один вопрос — одно сообщение. Кнопки + всегда можно написать текстом.
Кнопка до 64 символов. Не три вопроса сразу.

Не ИИ на каждую реплику. Скрипт + свои слова. Непредвиденное:
привет / цена / «ок» в бриф не кладём, шаг не двигаем.
Непонятное — переспросить кнопками, не гадать.

Первый экран: картинка уже есть (обложка про жест, не логотип).
Нужен новый текст к ней + одна главная кнопка.

Юридическое (152-ФЗ / правила MAX), не сюжет:
  на первом экране мелко: соглашение и политика (ссылки есть).
  Согласие на редкие сообщения в этот чат — да, иначе нельзя писать потом.
  Команду «стоп» бот обязан понимать. На первом экране её НЕ рекламировать.
  Гарантию «обязательно понравится» нельзя — оферта запрещает.
  Цену и «149 ₽» в чате не писать. Оффер: бесплатная проба, два варианта,
  минут пять.

Не делать:
  визитку студии первым сообщением;
  «вам это интересно?»;
  скидку с первого молчания;
  массовую рассылку «всем 8 марта»;
  ветку бизнеса как равную подарку;
  40 веток-лабиринтов. 3–5 живых сюжетов с развилками — да.
  Длиннее 6–7 шагов до студии — люди отвалятся. Лучше короче и теплее.

Технически в студию уйдёт один текст-бриф. Пишите его так, чтобы
продюсер понял: кому, повод, деталь, тон, голос. Без слова «подарок»
в первой строке (у нас из-за него песня уезжала в жанр «рок»).


6. ЧТО СДАТЬ (формат)
---------------------
1. Дерево веток на одной странице: вход → развилки → студия.
2. Таблица шагов:

   Шаг | Кто видит (какая ветка) | Текст бота | Кнопки |
   Своими словами (как понимать) | Что сохраняем | Следующий шаг

3. Финальное зеркало — 2–3 примера под разные ветки
   (маме на др / половинке просто так / «никому, просто внутри»).
4. Текст брифа в студию — те же 2–3 примера.
5. Три письма дожима (2 ч / сутки / 4 дня) + кнопка.
6. Список фраз, которые НИКОГДА не писать (канцелярит, ИИ, цена, стоп-призыв).

Язык: как человеку в чате в 2026, не как лендинг 2014.
Можно на «ты», если держится тепло и без панибратства.
Имя бота в чате: СоздайСвоюПесню. Не представляться «я нейросеть».


7. ОРИЕНТИР ВЛАДЕЛЬЦА (не копировать слепо)
------------------------------------------
Первый экран — живая мысль про то, что вслух не произносят, и желание
услышать. Не «соберём новую». Не инструкция про стоп.

Кому — тёплые кнопки в духе:
  моей маме / моему папе / моей половинке / дружбану / подругане /
  конкретно никому / напишу сам.

Не ставить «себе» рядом с «маме».
«Никому / просто так / другая причина» — свой сюжет, не день рождения.

Голос: женщина / мужчина / дуэт / мне всё равно, на твоё усмотрение.

Деталь — главный шаг для качества песни. Спрашивать человеческим языком,
с подсказкой под выбранную ветку. Не «что сейчас внутри».
Можно пропустить, но лучше захотеть ответить.
