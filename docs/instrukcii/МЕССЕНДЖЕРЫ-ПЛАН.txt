SongForge — Telegram / MAX / VK: как делать (решение)
======================================================
Обновлено: 4 сентября 2026
Код пока НЕ пилим. Это план, чтобы не строить три студии.

Короткий ответ
--------------
Сначала боты-продавцы + уведомления («песня готова»), со ссылкой на сайт.
Не отдельные приложения со всей студией.

Полную студию внутри мессенджера — только позже, и это тот же сайт
в оболочке, а не три копии.

Почему не три полноценных приложения
------------------------------------
Студия тяжёлая: идея, режимы, текст, 3–5 минут генерации, два варианта,
плеер, фонотека, оплата GetPlatinum.

Если собрать это заново в Telegram, MAX и VK:
  • три раза чинить баги;
  • три модерации;
  • три платёжки (Stars / СБП MAX / VK Pay) рядом с уже рабочей GP;
  • плеер в WebView слабый: звук часто стопорится в фоне,
    в Telegram нет нормального lock-screen плеера.

Генерация как раз любит чат: человек ушёл, бот написал «готово» и
прислал файл. В мини-приложении 5 минут смотреть спиннер — плохо.


Что умеют платформы (2026)
--------------------------

TELEGRAM
  Бот: кнопки, ссылка на сайт, sendAudio — трек слушается прямо в чате
       (это лучше, чем плеер внутри Mini App).
  Mini App: полноценный сайт внутри Telegram, вход по Telegram ID,
            оплата Stars / Telegram Pay.
  Минус Mini App: WebView, фон режет звук; Stars — отдельная касса
            от GetPlatinum. Для беты не смешивать.

MAX (мессенджер VK)
  Бот + мини-приложение (без бота мини-приложение не подключить).
  Bridge похож на Telegram. Платежи: СБП / карты через эквайер, не «касса MAX».
  Подключение: ИП / юрлицо / самозанятый РФ — у нас ИП подходит.
  API с июля 2026: platform-api2.max.ru (старый домен не использовать).
  Аудитория растёт (предустановка в РФ), перекрытие с Telegram не полное.

ВКОНТАКТЕ
  Бот сообщества + VK Mini Apps (сайт в iframe/WebView, VK Bridge).
  Вход VK ID у нас уже есть на сайте.
  Каталог приложений: основные функции нельзя уводить на чужой сайт.
    То есть «приложение-визитка со ссылкой на sozdaipesnu.ru» в каталог
    скорее не пустят. Бот сообщества + ссылка — можно.
  Свой контент (МузПлощадка) в Mini App = обязательная модерация UGC.
  Звук обязан выключаться при закрытии окна (VKWebAppViewHide).


Как делать оптимально
---------------------

Один продукт: сайт sozdaipesnu.ru
  студия, ноты, фонотека, шаринг, оплата GP.

Слой 1 (делать первым, после стабильной беты сайта)
  Один бот на канал. Три тонких клиента: Telegram, MAX, VK-сообщество.
  Одинаковый сценарий:
    1) Привет + что умеем + 1 бесплатная проба.
    2) Кнопка «Открыть студию» → https://sozdaipesnu.ru/?utm=tg|max|vk
    3) Когда трек готов — сообщение с файлом (или ссылкой /t/{id}).
    4) «Купить ноты» → та же оплата на сайте (GP), не новая касса.
    5) Короткий FAQ / support@, без дубля чата на сайте.

  Технически: один внутренний «messenger adapter» на сервере,
  три API снаружи. Аккаунт тот же (email / TG Login / VK ID уже есть).

Слой 2 (только если слой 1 живой и есть запрос «хочу не выходить из чата»)
  Mini App = тот же index.html в WebView.
  Вход: initData Telegram / MAX Bridge / VK launch params → наш user.
  Генерация как сейчас. Готовый трек — «отправить в чат» файлом.
  Оплата: сначала открывать форму GP; Stars/VK Pay — отдельное решение.

Не делать
---------
  • Три разных студии.
  • Оплату нот через Stars / VK Pay, пока GP на сайте работает.
  • Генерацию «диалогом в чате» вместо поля идеи (потеряем режимы и текст).
  • Каталог VK Mini Apps как визитку со ссылкой наружу.


Порядок, когда дойдём
---------------------
  1. Telegram-бот: визитка + «трек готов» файлом. У нас уже есть Login Widget.
  2. MAX-бот: тот же сценарий (ИП ок, нужен кабинет business.max.ru).
  3. VK: бот сообщества, не Mini App в каталоге.
  4. Mini Apps — по запросу, одна оболочка на тот же сайт.
