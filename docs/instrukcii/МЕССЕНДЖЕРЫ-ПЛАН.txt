SongForge — MAX / VK / Telegram: воронка, не три студии
======================================================
Обновлено: 4 сентября 2026
Код пока НЕ пилим.

Короткий ответ
--------------
ЦА сейчас в MAX и VK — ловим там.
Студию туда не переносим. Бот = живой продажник в чате:
прогрел → собрал «кому и зачем» → отправил на сайт сделать трек
→ если бросил, мягко напомнил → позже праздники/подарок.

Отдельный сервис внутри MAX/VK нагрузку с нашего сервера
почти не снимает. Дорожает поддержка, дешевле не становится.


Про нагрузку (важно)
--------------------
Мини-приложение VK/MAX — это наше же окно в их оболочке.
Песню всё равно считает наш сервер: Kie (текст), Suno (музыка),
диск, очередь. Это 95% нагрузки и денег.

Что «бесплатно» даёт мессенджер: вход, кнопки, доставка сообщения.
Чат почти ничего не весит. Генерация весит всегда.

Итог: отдельная студия в MAX/VK = та же нагрузка + три интерфейса.
Воронка = меньше случайных генераций (до сайта доходит тёплый),
плюс люди уже сидят там, где наша ЦА.


Почему не отдельные сервисы
---------------------------
• Студия тяжёлая: идея, режимы, 3–5 минут, два варианта, плеер, ноты, GP.
• Плеер в WebView рвётся в фоне. В чате файл слушается лучше.
• Три кассы (Stars / VK Pay / СБП) рядом с рабочей GP — путаница.
• VK: бот, который только гонит на чужой сайт, против правил
  (п.5 правил ботов). Он должен сам быть полезен, не «жми ссылку».
• MAX: массовая рассылка Bot API без договора — нельзя. Только тем,
  кто сам написал боту.

Позже можно открыть тот же сайт внутри MAX как мини-приложение
(короче путь, без браузера). Это удобство, не экономия сервера.
VK-каталог Mini Apps — ещё позже: модерация, UGC, нельзя уводить
наружу как главное действие.


Порядок каналов (под ЦА)
------------------------
1. MAX — приоритет.
2. VK-сообщество — второй.
3. Telegram — когда будет время (Login Widget уже есть).

Один сценарий, три тонких клиента. Один «продажник» внутри.


Как звучит (не как ИИ)
----------------------
На ты. Коротко. Один вопрос за раз.
Без «нейросеть воплотит ваши фантазии», без десяти кнопок,
без «спецпредложение только сегодня 🔥».

Как знакомый, который помогает сделать подарок, а не бот поддержки.

Нельзя: «Вы не завершили заказ. Вернитесь в воронку.»
Можно: «Ну как, открылось? Если зависло — напиши, гляну.»

Имя-маска («я Макс») не брать — путаница с мессенджером.
Говорим от студии на ты, без представления роботом.


Сценарий воронки
----------------

ШАГ 1. Человек сам написал / нажал Старт
  «Привет. Сделаем песню — себе или в подарок?»
  Кнопки: Себе / В подарок / Пока слушаю

ШАГ 2. Прогрев (бот полезен уже в чате)
  Подарок → «День рождения, свадьба или просто так?»
  Потом: «Кинь пару фраз: кто человек и что сказать.
  Можно коряво — на сайте докрутим.»
  Себе → «О чём песня? Настроение любое — злость, нежность, драйв.»
  Бот коротко пересказывает идею своими словами:
  «Ок. Грустная поп-песня маме, что всегда была рядом. Так?»
  Человек поправляет. Это и есть «живой», не меню.

ШАГ 3. Переход на сайт (одна кнопка, одно дело)
  «Есть одна бесплатная проба. Сейчас открою студию —
  вставь эту мысль в поле идеи. Минут через 5 будут два варианта.
  Я тут, если застрянешь.»
  Ссылка: https://sozdaipesnu.ru/?utm=max (или vk)
  Не лендинг с десятью экранами — сразу студия.

  VK: ссылка не единственная польза. Сначала идея собрана в чате.

ШАГ 4. Если бросил (дожим, не спам)
  Знаем только если человек писал боту и/или вошёл на сайт
  тем же VK/MAX. Холодным не писать.

  Через ~2 часа, один раз:
  «Ну как, открылось? Если крутилка или не пускает — напиши.»
  На следующий день, один раз:
  «Идея ещё тут. Могу ссылку кинуть ещё раз — или отложим,
  напишешь когда будет минута.»
  Дальше про эту песню молчим. Не каждый день.

  После пробы без покупки (если аккаунты связаны), через 1–2 дня:
  «Как первый трек? Если мимо — можно крутануть с другой мыслью.
  Ноты — когда сам захочешь, не давлю.»

ШАГ 5. Праздники / подарок (только по согласию)
  После первой пользы, не в первом сообщении:
  «Напомнить перед праздниками? 8 марта, НГ, ДР если скажешь дату.
  Редко, по делу. Напиши «стоп» — отключу.»
  Без согласия — не рассылаем.

  Пример 8 марта, за неделю:
  «Слушай, 8 марта через неделю. Если ещё без подарка —
  песню успеем. Напиши кому — набросаем текст.»

  Частота рекламы ВК: не чаще 1 раза в 7 дней, кнопка отписки,
  пометка рассылки. MAX: только тем, кто сам начал диалог,
  без массовой «базы». Сервисные («трек готов») — отдельно,
  это не реклама.


Что бот шлёт сам (сервис)
-------------------------
• Трек готов — файл или ссылка /t/{id}
• Оплата прошла — ноты на месте
• Генерация упала — «сорри, давай ещё раз, не списывал»

Это не продажи, это забота. Тон тот же, по-свойски.


Технически (когда дойдём, не сейчас)
------------------------------------
Один мозг на сервере, три тонких API: MAX, VK, TG.
Аккаунт тот же. VK ID на сайте уже есть — дожим после сайта
в ВК реален. MAX-вход на сайте ещё нет: дожим после сайта
в MAX слабее, пока человек не вернулся в бота сам.

Оплата всегда GetPlatinum на сайте. В чате не собираем карты.

Не делать
---------
• Три студии
• Новую кассу в мессенджере
• Генерацию целиком диалогом (потеряем режимы и текст)
• Массовые рассылки незнакомым
• Давить каждый день
• ИИ-тон и промо-огоньки


Когда делать
------------
После того как сайт стабилен (оплата, проба, хиты ок).
Первый канал — MAX. Потом VK. Код не писать, пока не скажете.
