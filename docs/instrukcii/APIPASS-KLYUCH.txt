Как вписать ключ ApiPass
========================
Ключ берёшь в кабинете ApiPass, не из чата.
В чат ключ не копируй.

1. Открой кабинет ApiPass в браузере.
   Найди API Key. Скопируй его там (кнопка Copy).

2. На сервере, где строка root@, вставь ОДНУ строку
   из COMMANDS.txt, блок 54:

   nano /root/SongForge/.env

3. Откроется файл. Стрелками найди строку:

   APIPASS_API_KEY=

   После знака = сотри старое значение и вставь ключ из кабинета.
   Пробелов вокруг ключа быть не должно.
   Кавычки не ставь, если их не было.

   Было примерно:
   APIPASS_API_KEY=старый_ключ

   Стало:
   APIPASS_API_KEY=новый_ключ_из_кабинета

4. Сохранить и выйти:
   Ctrl+O   (записать)
   Enter
   Ctrl+X   (выйти)

5. В COMMANDS.txt блок 52 — две строки, по одной:

   pm2 restart songforge --update-env
   pm2 restart songforge-worker --update-env

Готово. Ключ в чат не присылай.
