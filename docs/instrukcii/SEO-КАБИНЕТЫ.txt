ТРИ РАЗНЫХ КАБИНЕТА (не путать)
-------------------------------
1) Google Search Console  — Google видит сайт, карта сайта, «запросить индекс»
2) Яндекс.Вебмастер       — то же для Яндекса (в РФ важнее Google)
3) Яндекс.Метрика         — сколько людей зашло, откуда, что нажали
   Это НЕ поиск. Это счётчик на сайте. Ставить только после согласия на cookie.

Поиск (1 и 2) и Метрика (3) — разные сайты Яндекса/Google.
Рекламу Директ / Google Ads пока не подключаем.


ЧТО УЖЕ СДЕЛАНО В КОДЕ (сайт sozdaipesnu.ru)
--------------------------------------------
• https://sozdaipesnu.ru/robots.txt
• https://sozdaipesnu.ru/sitemap.xml
• title, description, canonical, картинка при шаринге
• файл подтверждения Google уже лежит:
  https://sozdaipesnu.ru/googleb1701eb0e8593baa.html

ни Google, ни Яндекс его не видят. Как сделать адрес — раздел Г.

А. GOOGLE SEARCH CONSOLE (сайт)
═══════════════════════════════════════

1) Открыть: https://search.google.com/search-console
   Войти Google-аккаунтом владельца (тот, который ваш).

2) «Добавить ресурс» → тип «URL-префикс»:
   https://sozdaipesnu.ru
   (со слешем в конце или без — как предложит Google, главное https)

3) Подтверждение. Способ «HTML-файл».
   Файл googleb1701eb0e8593baa.html на сайте УЖЕ есть.
   Нажать «Подтвердить». Должно пройти сразу.

   Если Google просит ДРУГОЕ имя файла или HTML-тег —
   скопируйте строку целиком и пришлите ассистенту, не вставляйте сами.

4) Слева «Файлы Sitemap» (или «Файлы Sitemaps») → добавить:
   https://sozdaipesnu.ru/sitemap.xml
   Сохранить. Статус «успешно» может появиться не сразу — это нормально.

5) Сверху «Проверка URL» → вставить:
   https://sozdaipesnu.ru/
   → «Запросить индексирование».

6) Проверка для себя через несколько дней, в Google:
   site:sozdaipesnu.ru
   Если главная видна — сайт в индексе. В топ по «создай свою песню»
   новый сайт без рекламы не попадёт быстро — это нормально.


═══════════════════════════════════════
Б. ЯНДЕКС.ВЕБМАСТЕР (сайт)
═══════════════════════════════════════

1) Открыть: https://webmaster.yandex.ru
   Войти Яндекс-аккаунтом владельца.

2) «Добавить сайт»:
   https://sozdaipesnu.ru

3) Подтвердить, что сайт ваш. Удобнее всего «HTML-файл»
   (Яндекс даст имя вроде yandex_XXXXXXXX.html и одну строку внутри).

   НЕ кладите файл сами. Скопируйте:
     • имя файла (yandex_....html)
     • содержимое одной строки
   и пришлите ассистенту одним сообщением.
   Вставлю в код, запушу. После деплоя нажмёте «Проверить» в Вебмастере.

   Запасной способ — «Мета-тег»:
   Яндекс даст:
     <meta name="yandex-verification" content="XXXX" />
   Пришлите content="...." — тоже вставлю.

4) Когда сайт подтверждён: «Индексирование» → «Файлы Sitemap» → добавить:
   https://sozdaipesnu.ru/sitemap.xml

5) «Переобход страниц» → добавить https://sozdaipesnu.ru/ → отправить.

6) Проверка через несколько дней, в Яндексе:
   site:sozdaipesnu.ru

В. ЯНДЕКС.МЕТРИКА (счётчик)
═══════════════════════════════════════

Это не поиск. Это «сколько зашло». Код счётчика в сайт вставляю Я,
только после вашего номера. Сами в index.html ничего не копируйте.

1) Открыть: https://metrika.yandex.ru
   Тот же Яндекс-аккаунт, что и Вебмастер — так проще.

2) «Добавить счётчик».

   Имя:        СоздайСвоюПесню
   Сайт:       sozdaipesnu.ru
   Часовой пояс: Москва (или ваш)

   Галочки на старте:
     • Вебвизор — можно включить (записи визитов, удобно смотреть)
     • Карта кликов — можно
     • Информер — не нужен
     • Приём данных с неяндексовых доменов — пока не нужен

3) Согласие с офертой Метрики → создать.

4) Яндекс покажет номер счётчика (цифры, например 98765432)
   и кусок JavaScript. Номер — это главное.

5) Пришлите ассистенту ОДНУ строку:
     Метрика сайт: 98765432

   Я вставлю счётчик так:
     • грузится только если человек нажал «Принять все» в cookie
     • «Отклонить» / «Только необходимые» — счётчика нет
   Это уже заложено в баннере сайта.

6) Цели в Метрике (нажмите сами после того, как счётчик на сайте):
   Пока хватит 3 штук, без фанатизма:
     • Вход (URL содержит auth=ok) — «посещение страницы»
     • Оплата ок (URL содержит payment=success)
     • Оплата нет (URL содержит payment=failed)
   UTM с ленда (utm_source=landing) Метрика подхватит сама,
   когда ленд начнёт слать людей на sozdaipesnu.ru.

7) Второй счётчик на ленд — ПОТОМ, когда поддомен откроется.
   Можно тот же номер (в настройках счётчика добавить адрес ленда)
   или отдельный. Проще один номер на оба, когда ленд живой.
   Напишите — подскажу в момент подключения.

Г. ЛЕНДИНГ: ПОДДОМЕН, НЕ ВТОРОЙ ДОМЕН
═══════════════════════════════════════

Короткий ответ: отдельный домен НЕ обязателен.
Достаточно поддомена на уже купленном sozdaipesnu.ru.

Почему так
----------
• Домен уже ваш, DNS уже в REG.RU, почта уже настроена.
• Студия остаётся на https://sozdaipesnu.ru
• Ленд — отдельный адрес, например https://podarok.sozdaipesnu.ru
• Поиск считает это двумя сайтами — так и нужно:
  ленд продаёт, студия делает песню. Кабинеты заводим отдельно.
• Не кладём ленд «внутрь» sozdaipesnu.ru/landing — студия это сломает.

Как будет устроено
------------------
Поддомен смотрит на ТОТ ЖЕ сервер (195.19.20.245).
Nginx отдаёт папку landing/ как простой сайт. Студию не трогает.
Второй хостинг Timeweb/Beget не нужен.

Имя поддомена (рекомендуем):
  podarok.sozdaipesnu.ru

Запасные, если это имя не нравится:
  gift.sozdaipesnu.ru
  go.sozdaipesnu.ru

Напишите, какое имя берём. Дальше:

ШАГ Г1. DNS в REG.RU (делаете вы)
  Домены → sozdaipesnu.ru → DNS-серверы и зона → «Добавить запись»

  Тип:       A
  Subdomain: podarok     (без точки и без sozdaipesnu.ru)
  IP:        195.19.20.245
  Сохранить.

  Записи A @ и A www НЕ трогать.

ШАГ Г2. Написать ассистенту: «DNS podarok добавил»
  На сервере: nginx + HTTPS (замочек) на этот поддомен,
  выкладка файлов из landing/. og-теги переключим на поддомен.

ШАГ Г3. Проверка
  https://podarok.sozdaipesnu.ru открывается, кнопки ведут
  на sozdaipesnu.ru с utm_source=landing.

Отдельный домен (pesnya-podarok.ru и т.п.) — по желанию ПОЗЖЕ,
если захотите ключ прямо в имени. Для открытия это лишние деньги
и второй комплект SSL/кабинетов. Сейчас не нужно.
